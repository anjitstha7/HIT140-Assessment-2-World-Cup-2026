# FIFA World Cup 2026 – Team Discipline Analysis

## Focus
This analysis examines team discipline using yellow cards.

## Research Question
Is there a statistically significant difference in the average number of yellow cards per 90 team-minutes between teams that progressed to the knockout stage and teams eliminated in the group stage?

## Data
The analysis uses FIFA World Cup 2026 team-level statistics from FBref.

## Analysis
The Python code covers:
- Data cleaning
- Sampling
- Yellow cards per 90 team-minutes
- Descriptive statistics
- 95% confidence intervals
- Welch two-sample t-test
- Effect size
- Visualisation
